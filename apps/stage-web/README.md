## Agent backend

Nút chọn agent backend (opencode, Claude Code) ở góc trên trái của bản web chỉ lưu lựa chọn lại.
Bản web không chạy được backend: việc đó cần tiến trình main của app desktop, và proxy của app
desktop đòi một token sinh mới mỗi lần mở app mà trình duyệt không có. Thẻ dưới nút vẫn hiện tên
phiên trò chuyện như bản desktop.
